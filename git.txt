================ GITHUB AND GIT COMMANDS STEPS ================

Step 1: Create GitHub Account

1. Open browser
2. Go to GitHub
3. Click Sign Up
4. Enter:
   - Email
   - Password
   - Username
5. Verify account
6. GitHub account created

--------------------------------------------------

Step 2: Install Git

Download Git from:

Git Download

Install with default settings.

--------------------------------------------------

Step 3: Configure Git

Open terminal or command prompt and run:

git config --global user.name "Your Name"

git config --global user.email "youremail@gmail.com"

--------------------------------------------------

Step 4: Create New Repository on GitHub

1. Login to GitHub
2. Click New Repository
3. Enter repository name
4. Click Create Repository

Example:

college-dashboard

--------------------------------------------------

Step 5: Open Project Folder

Open terminal inside your project folder.

Example:

cd Desktop/project

--------------------------------------------------

Step 6: Initialize Git

git init

Meaning:
Creates local git repository.

--------------------------------------------------

Step 7: Add Files

git add .

Meaning:
Adds all files to staging area.

--------------------------------------------------

Step 8: Commit Files

git commit -m "First Commit"

Meaning:
Saves project changes.

--------------------------------------------------

Step 9: Connect GitHub Repository

git remote add origin https://github.com/username/repository-name.git

Example:

git remote add origin https://github.com/sagar123/college-dashboard.git

--------------------------------------------------

Step 10: Push Code to GitHub

git push -u origin master

or

git push -u origin main

Meaning:
Uploads code to GitHub.
