1) Responsive Web Page using HTML, CSS, Bootstrap
--------------------------------

Q1. What is HTML?
Answer:
HTML (HyperText Markup Language) is used to create the structure of web pages.

Q2. What is CSS?
Answer:
CSS (Cascading Style Sheets) is used for styling web pages.

Q3. What is Bootstrap?
Answer:
Bootstrap is a CSS framework used to create responsive websites.

Q4. What is a responsive website?
Answer:
A responsive website adjusts according to screen size.

Q5. What is Bootstrap grid system?
Answer:
Bootstrap uses a 12-column grid system.

Q6. Difference between id and class?
Answer:
id is unique while class can be used multiple times.

Q7. What is media query?
Answer:
Media query is used for responsive design.
